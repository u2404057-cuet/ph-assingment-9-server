# DriveFleet Server

This is the Express.js backend for the DriveFleet application.

## Setup Instructions

1. Run `npm install` to install dependencies.
2. Create a `.env` file in the root of the project with the following variables:
   ```env
   PORT=8000
   MONGO_URI=your_mongodb_connection_string
   ```
3. Run `npm run dev` or `nodemon index.js` to start the server.
